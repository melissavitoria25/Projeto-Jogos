# Além das luzes

Jogo de plataforma 2D em que você controla dois personagens que coletam orbes de luz pelo caminho atravessando obstáculos ao longo da jornada. 

**Status:** em desenvolvimento 🚧

## Funcionalidades

- Movimentação do jogador em 2D
- Orbes de luz coletáveis
- Obstáculos com espinhos
- Gerenciamento de cenário

## Controles

| Ação | Tecla |
|------|-------|
| Mover | [A / D ou setas] |
| Pular | [Espaço] |
| Trocar Player | [Q] |

## Tecnologias

- [Unity](https://unity.com/) 
- C#
- Física 2D da Unity

## Como rodar o projeto

1. Instale o [Unity Hub](https://unity.com/download) e a versão da Unity indicada acima.
2. Clone o repositório:
   ```bash
   git clone git@github.com:melissavitoria25/Projeto-Jogos.git
   ```
3. No Unity Hub, clique em **Add → Add project from disk** e selecione a pasta clonada.
4. Abra o projeto e carregue a cena `Assets/Scenes/SampleScene`.
5. Clique em **Play**.

## Estrutura do projeto

```
Assets/
├── Scenes/      # Cenas do jogo
└── Scripts/     # Código em C# (Player, GerenciadorCenario, Espinhos, OrbeLuz...)
Packages/
ProjectSettings/
```
